集市互动

每天自动给 TA 添这么多同心币，钱花光了集市也不会突然安静下来；填 0 就不发。TA 买过 / 送过的东西会避开最近几件，不会连着抽到同一个。

当前：平均每 180 分钟（3 小时）有一次机会。

填几就是一天最多几条，间隔不用自己填，自动按 24 小时平均：填 8 是平均 3 小时一次，填 1 是一天一次，填 0 就是彻底不发。每天发满就安静，第二天零点自动恢复。

每次机会里，5 件事各按自己的概率独立判定，命中才发一条、一次最多一条；都没命中就这一次什么都不发，等下次机会。

填的数字就是概率本身：填 1 就是 1%，填 100 就是 100%，1~100 之间随便填，没有隐藏换算。这 5 个概率各自独立生效，每次机会每件事都按自己的概率单独判定一次，数值越小，那件事出现得越少，填 0 就基本不会出现。

同一轮即使有好几件事同时命中，也只会随机挑一件发出来，一次最多一条，不会一次刷出一堆；一件都没命中就什么都不发，等下一次逛集市再判。

你在集市许愿后，TA 看到时有概率直接答应并送你（已接受），也可能拒绝（已被拒绝）；剩下的概率不作处理，保持等待。

把已经收下/退回/买下、以及放了超过 24 小时过期的集市卡片（含集市订单）从聊天里清掉；还没处理的礼物和心愿会保留。聊天记录里的其它消息不受影响。

闹钟「时钟 → 闹钟」里设定时间并打开开关；页面保持打开时每秒检测一次，时间对上就弹全屏毛玻璃、随机抽一张字卡，并播放选好的音色（可选「静音」只弹窗）。
专注计时「时钟 → 专注计时」选 25 / 15 / 5 分钟开始倒计时，走完同样弹窗抽字卡。
世界时间进入「时钟 → 世界时间」会生成一个带零头的随机时差（比如慢 4 小时 19 分），点「重新拨动时差」可换一个。
02

TA 主动找你

都是各自独立的投放：听歌 / 问卷 / 写信 / 拍一拍按各自冷却投一次，主动发消息按空闲每 N 分钟投一次。概率填 0 就彻底关掉

主动发消息你没发消息的空闲里，每隔「投放间隔」分钟投一次骰子；投中才开口（按命中率），没中就等下一轮，一次随机发几条，不设每日上限。
拍一拍TA 自己找时机拍你，跟发字卡无关：冷却 5 分钟（写死、不可调、不进设置），冷却结束按「TA 拍我（%）」投一次，投中才拍，没中就再等一轮。每个角色各算各的，不限每日次数。
邀请一起听歌邀请出现后开始计冷却；冷却结束按「TA 邀请一起听音乐（%）」投一次，投中才发，没中就再等一轮。冷却在聊天设置 → 音乐互动里调。
主动写信信寄到后开始计冷却；冷却结束按「TA 主动写信（%）」投一次，中不中都重新冷却。概率和冷却在设置 → 后台 → 信里调。
主动发问卷问卷出现后开始计冷却；冷却结束按「TA 主动发问卷（%）」投一次，没中就再等一轮。概率和冷却在设置 → 后台 → 问卷里调。
发朋友圈 / 点赞评论TA 按每日条数上限和冷却间隔发动态；你发了动态后，TA 再按点赞、评论概率来互动。
逛集市每 60 秒检查一次，按概率触发，受「每日主动集市次数」限制。
换头像 / 改名字按各自概率与冷却时间触发；新头像来自「头像工具」的头像池，新名字来自「名字」分类，池子空了就不会换。
引用 / 语音 / 表情包 / 撤回 / 收藏 / 已读不回你发消息之后，TA 按各自概率决定要不要做这些，概率都在「聊天设置」里。
字卡征询你发完消息后，TA 有概率问「这句能不能收进字卡库的聊天分类」，同意才会加。
冷却与投放听歌 / 问卷 / 写信都是「内容出现 → 计冷却 → 结束投一次 → 中不中都重新冷却」；主动发消息例外，按你不发消息的空闲每 N 分钟投一次。都不再限每日次数。

怎么把内容加进去

库里有东西，上面那些功能才有得抽

字卡「字卡库」新建，可写触发词；TA 说话时按内容和触发词、分类匹配。批量导入可以一次填多条。
语音卡字卡库「语音」分类导入一段 mp3，并写下它说的话；聊天里点语音会播这段。
表情包表情包页「从本地相册添加」，或直接粘贴截图。

音乐「音乐」里导入网易云链接或本地音频后才有播放列表；听歌猜名的曲库也来自这里。
契约书背景婚帖签完后，「上传图片」或直接粘贴截图，只换卡片内部背景。

时钟 · 婚帖 · 塔罗

三个新应用的完整走法

婚帖第二页「婚帖」→ 先选契约对象、换双方头像（按联系人各存各的）→ 前往登记 → 确认框 → 心跳动画 → 生成契约书。日期默认今天、可改任意日期；签完才放开换背景、换誓词、保存为图片。

闹钟到点必须页面保持打开；锁屏或切后台久了，浏览器会冻结定时器，不保证准点响。
纯前端这站没有服务端，所有定时检测都在你手机上跑。
